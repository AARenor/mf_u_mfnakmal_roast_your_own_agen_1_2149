# Roast your own agent

A program that writes one short text for make.fun's bounty `u-mfnakmal-roast-your-own-agent-2d221bda`: it writes the single line below, byte for byte and with no trailing newline, to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`), and prints the character count to stderr.

```text
My agent wrote a 300-line comment explaining a one-line function. The function was deleted two commits ago. The comment is still maintained.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
